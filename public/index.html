What input works?
  • [{…}, {…}] or JSON Lines (one object per line) makes one sheet.
  • {"Students": [...], "Courses": [...]} makes one sheet per key (Excel only).
  • Nested objects get their own columns: address.city becomes Address City.
  • Dates like 2024-01-15 become real Excel dates; IDs over 15 digits stay exact.
  • Python-style input works too: single quotes, True/None.
Limits
  • Excel: 1,048,575 rows, 16,384 columns and 32,767 characters per cell.
  • Hosted on Vercel: 4.5 MB per upload after compression, which is often 20 MB+ of JSON.
  • Run it yourself for bigger data: up to 100 MB by default.
